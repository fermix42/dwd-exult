ARCHITECTURE VERIFIED
Effects_manager creates Text_effect for both speech and unrelated text. The actual
accepted fork uses ++num_ticks == 10 in Text_effect::handle_event, per visible page.
init queues the first event immediately, set_always(true) retains existing pause
behavior, and later events requeue at Game::get_ticks()+get_std_delay(). Timing is
in scheduled updates, not a new real-time service or game-calendar timer.

Actor-backed Game_object::say and Usecode_internal::item_say share this effect.
A call-site audit also found the original Avatar got_bad_feeling bark entering the
manager directly. All three speech entry points now request the same global rule.
Damage numbers and name labels also use Text_effect, so a simple optional speech
argument at the existing factory distinguishes them. Positional/centered messages
and non-actor object messages keep ten updates. Books, portrait conversations,
tooltips and case labels use their original paths and remain unchanged.

The manager's existing duplicate and Usecode replacement behavior is preserved.
Explicit script replacement/manual clearing/scene cleanup can still end a bark
before its automatic timeout, just as before. Longer timers do not override scripts.

IMPLEMENTATION / OPTIONS / CONFIG
One Game_window preference: config/gameplay/overhead_text_duration in exult.cfg.
Supported integer percentages: 50,100,150,200,300. Strict missing/malformed/
unsupported input defaults to 100; runtime validation has the same bounded choices.
The preference does not write save-game state or alter any save format.

Escape -> Game Display -> Overhead Text Duration (below Text Background).
Existing cycling toggle, font and procedural Options style; no new settings window.
Short (50%), Normal (100%, default), Longer (150%), Double (200%), Triple (300%).
Left mouse cycles forward, native right mouse backward. In this display gump,
Left/Right adjust this preference using the existing toggle callback; Enter saves,
Escape cancels through normal modal handling. Other Options controls are unchanged.
This is narrowly scoped keyboard support, not a general menu-navigation rewrite.
OK/checkmark use existing save_settings/config->write_back; reopening shows the
current value, and the saved preference applies to newly created speech immediately.

A Text_effect captures lifetime_ticks at creation: 10*percent/100, implemented as
percent/10 for the five exact supported values. Result: 5,10,15,20,30 callbacks per
page. The default retains the original ten callbacks, the same first scheduling,
subsequent cadence, counter/page transition, dirtying and destruction. No queue
entry is added/rebuilt on a settings change. Visible text retains its captured timer,
including later pages. No extra text-length or character-specific duration rule.

Production files: effects.cc/.h, gamewin.cc/.h, objs/objs.cc, usecode/ucinternal.cc,
gumps/GameDisplayOptions_gump.cc/.h. gumps/Text_button.h adds a read-only text getter
for native-control observations. Accepted layout, wrapping, painting, tracking,
positioning, init and cleanup regions compare byte-identical to baseline after
normal checkout newline normalization (renderer-preservation.json). Only the timer
predicate/factory/construction change inside Text_effect. No font/scaling edits.
